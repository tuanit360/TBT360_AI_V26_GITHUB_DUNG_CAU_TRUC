# TBT360 AI V65 - Ban V2 sua loi cai Python Windows

## Nguyen nhan da xac minh
Log tu may Dell cho thay Python 3.11.9 da duoc cai, Python installer chay "Modify" va tra exit=0 nhung khong tao python.exe tai runtime\Python311. Vi vay ban cu dung chuong trinh cai dat sai cach khi Python da ton tai.

## Cach chay
1. Giai nen ZIP vao duong dan ngan, vi du C:\TBT360_AI_V65 (khong can xoa Python hien co).
2. Nhan dup `CAI_DAT_VA_CHAY.bat` (ket noi Internet de cai thu vien AI).
3. Ban moi tim Python 3.11 x64 hien co trong Windows Registry, Python Launcher va duong dan thong dung. Tao virtual environment trong runtime\ai_env ma khong sua Python he thong.
4. Neu van loi, gui logs\bootstrap.log va anh chup man hinh. Dung `KIEM_TRA_PYTHON_WINDOWS.bat` de lay danh sach Python.

Luu y: Goi nay gom ma nguon va bo cai phu thuoc online, khong gom san Python/PyTorch/model AI. Chua the chay end-to-end tren Windows tu moi truong Linux dung de dong goi.
