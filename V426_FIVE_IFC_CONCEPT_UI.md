# Five IFC concepts directly inside BIMAI360

New button in the existing image tab generates 5 IFC4 concept models from the uploaded reference image. Geometry (architecture, structural, electric, plumbing) is explicitly assumed; the photo does not provide hidden MEP or engineering details. Output is a downloadable ZIP with one IFC per option, manifest and reference thumbnail. IfcOpenShell is used to author and reopen each IFC; Windows build now collects its package. No changes to existing controls. No engineering verification or image-based 3D reconstruction claimed.
