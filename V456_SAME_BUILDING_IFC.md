# One source building, five IFC design alternatives

Change of semantics: PA01–PA05 now share a single assumed exterior
envelope, project reference and elevations. They differ in internal
partition and sanitary-service layout; the exterior structure remains
unchanged. ZIP contains only five IFC files and JSON manifest (no PNG).

This is a conceptual editable handoff, **not** photo reconstruction or
complete engineered electrical/plumbing/structural design. Image does not
give reliable interior, measurements, loads or routes; these remain explicit
assumptions. Existing image generation controls remain available unchanged.
